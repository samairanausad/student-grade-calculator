# Student Grade Calculator

A beginner-friendly Python project that calculates a student's total marks, percentage, and grade.

## Features

- Takes student name as input
- Takes marks for 5 subjects
- Calculates total marks
- Calculates percentage
- Assigns a grade based on percentage

## Technologies Used

- Python

## How to Run

Run the `student_grade_calculator.py` file and enter the student's name and marks when prompted.
